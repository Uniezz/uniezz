# Uniezz web

Vite + React + TanStack Router.

## Development

```bash
bun install
bun run dev
```

App runs at http://localhost:7711.

| Command             | Description      |
| ------------------- | ---------------- |
| `bun run dev`       | Dev server       |
| `bun run build`     | Production build |
| `bun run typecheck` | Type-check       |
| `bun run lint`      | Lint             |
